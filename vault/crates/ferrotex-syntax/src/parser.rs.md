# `crates/ferrotex-syntax/src/parser.rs`

## Purpose & Architecture Role

`crates/ferrotex-syntax/src/parser.rs` implements the core LaTeX parser for FerroTex. Operating directly on token streams generated by the [[crates/ferrotex-syntax/src/lexer.rs|lexer.rs]], it constructs a **lossless Concrete Syntax Tree (CST)** using the `rowan` library (red-green tree architecture).

The parser is explicitly architected for **fault-tolerant, resilient language server operation**:
- It tolerates incomplete syntax (e.g., during active user typing).
- It generates a valid CST even when errors are present, ensuring downstream features (syntax highlighting, completions, hovers, navigation) remain responsive.
- It produces exact source offsets and structured error diagnostics (`SyntaxError`).
- It serves as the primary syntactic foundation for [[crates/ferrotex-syntax/src/lib.rs|syntax lib.rs]] and the entire `ferrotexd` LSP server ecosystem.

```text
┌─────────────────────────┐
│ LaTeX Source Code (&str) │
└────────────┬────────────┘
             │
             ▼
   [[crates/ferrotex-syntax/src/lexer.rs|lexer.rs]] (Peekable<Lexer<'a>>)
             │ Tokens (SyntaxKind, &str)
             ▼
   [[crates/ferrotex-syntax/src/parser.rs|parser.rs]] (Parser<'a>)
             │ Recursive Descent + Error Recovery
             ▼
        ParseResult
     ├── GreenNode (Rowan CST)
     └── Vec<SyntaxError>
```

## Key Symbols & Interfaces

### Structs & Types

#### `SyntaxError`
Represents a syntactic diagnostic encountered during parse tree construction.
- `pub message: String` — Human-readable description of the syntax issue.
- `pub range: TextRange` — Precise text byte range span in the source code.

#### `Parser<'a>`
The internal recursive descent parser struct managing parser state and tree construction.
- **Fields:**
  - `lexer: Peekable<Lexer<'a>>` — Buffered token iterator over the LaTeX source.
  - `builder: GreenNodeBuilder<'static>` — Rowan green-tree builder accumulating composite nodes and tokens.
  - `errors: Vec<SyntaxError>` — Diagnostic error collector for recoverable syntax faults.
  - `current_offset: TextSize` — Text cursor offset tracker for error positioning.
- **Public Methods:**
  - `pub fn new(input: &'a str) -> Self` — Instantiates a parser over an input string.
  - `pub fn parse(mut self) -> ParseResult` — Driver method executing root-level parsing (`SyntaxKind::Root`) until `SyntaxKind::Eof`.
- **Parsing & Dispatch Methods:**
  - `parse_element(&mut self)` — Top-level element dispatcher routing commands, groups, errors, or raw tokens.
  - `parse_command_or_environment(&mut self)` — Dispatches specialized commands:
    - `\begin` $\to$ `parse_environment()`
    - `\section` $\to$ `parse_section()`
    - `\input` / `\include` $\to$ `parse_include()`
    - `\label` $\to$ `parse_label()`
    - `\ref` $\to$ `parse_ref()`
    - `\cite` $\to$ `parse_citation()`
    - `\bibliography` / `\addbibresource` $\to$ `parse_bibliography()`
  - `parse_group(&mut self)` — Parses `{ ... }` blocks into `SyntaxKind::Group` nodes.
  - `parse_environment(&mut self)` — Parses `\begin{...} ... \end{...}` blocks into `SyntaxKind::Environment`. Handles nested environments and validates delimiter symmetry.
  - `parse_section(&mut self)` — Parses section headers into `SyntaxKind::Section`.
  - `parse_include(&mut self)` — Parses file inclusion directives into `SyntaxKind::Include`.
  - `parse_label(&mut self)` — Parses label declarations into `SyntaxKind::LabelDefinition`.
  - `parse_ref(&mut self)` — Parses cross-references into `SyntaxKind::LabelReference`.
  - `parse_citation(&mut self)` — Parses citation commands (`\cite[...]{...}`) into `SyntaxKind::Citation`.
  - `parse_bibliography(&mut self)` — Parses bibliography declarations into `SyntaxKind::Bibliography`.
- **Lexer Navigation & Lookahead Helpers:**
  - `peek(&mut self) -> SyntaxKind` — Inspects the kind of the upcoming token without consuming it.
  - `peek_text(&mut self) -> &str` — Inspects the slice of the upcoming token.
  - `bump(&mut self)` — Consumes the next token and adds it to the green tree builder.
  - `error(&mut self, message: String)` — Emits a `SyntaxError` at the current offset.
  - `get_group_text_peek(&mut self) -> String` — Clones the lexer to extract group text (such as environment names) ahead of consumption.

#### `ParseResult`
The output package of a completed parse operation.
- `green_node: GreenNode` — The untyped Rowan green tree root.
- `pub errors: Vec<SyntaxError>` — List of syntax errors accumulated during parsing.
- **Methods:**
  - `pub fn syntax(&self) -> SyntaxNode` — Produces the root red tree `SyntaxNode` for traversal and inspection.
  - `pub fn green_node(&self) -> GreenNode` — Returns a clone of the underlying `GreenNode`.

### Free Functions

#### `pub fn parse(text: &str) -> ParseResult`
The primary public entry point for parsing LaTeX code in FerroTex.

```rust
use ferrotex_syntax::parse;

let result = parse(r"\section{Introduction} Hello world!");
let root = result.syntax();
assert!(result.errors.is_empty());
```

## AST & CST Node Types

The parser emits composite nodes classified by `SyntaxKind`:

| `SyntaxKind` | Node Type | Example Source Representation |
|---|---|---|
| `Root` | Document root | Entire parsed source buffer |
| `Group` | Braced block | `{ \bfseries bold }` |
| `Environment` | Scoped environment | `\begin{equation} ... \end{equation}` |
| `Section` | Document heading | `\section{Title}` |
| `Include` | Document inclusion | `\input{chapter1}`, `\include{preamble}` |
| `LabelDefinition` | Label marker | `\label{sec:intro}` |
| `LabelReference` | Cross reference | `\ref{sec:intro}` |
| `Citation` | Bibliography citation | `\cite[Theorem 1]{knuth1984}` |
| `Bibliography` | Bibliography resource | `\bibliography{refs}`, `\addbibresource{refs.bib}` |
| `Error` | Syntactic anomaly node | Stray closing braces `}` |

## Error Recovery Strategy

LaTeX documents in real-world IDE workflows are frequently incomplete, invalid, or mid-edit. The parser employs several distinct resilience mechanisms:

1. **Non-Aborting Recursive Descent**:
   - The parser never panics or halts when unexpected tokens occur; it records errors and resumes consumption.
2. **Missing Delimiter Toleration**:
   - In `parse_group`, if EOF is encountered before `}`, an `Expected '}'` error is recorded, but the group node is finished gracefully (`builder.finish_node()`), preserving tree hierarchy for ancestor and sibling elements.
   - In optional brackets (`[...]` in citations or bib resources), missing `]` triggers a non-fatal error while continuing to parse the subsequent required group `{...}`.
3. **Dedicated Error Nodes for Rogue Tokens**:
   - When encountering an unmatched `}` at root level or inside an environment, the parser wraps it into a `SyntaxKind::Error` node (`builder.start_node(SyntaxKind::Error.into())`), bumps the token, and closes the node, preventing cascaded stack imbalances.
4. **Environment Lookahead and Resynchronization**:
   - `get_group_text_peek()` clones the lexer to inspect environment identifiers (`\begin{name}` vs `\end{name}`).
   - If EOF is hit inside an unclosed environment, it records `"Unclosed environment, expected \\end"` and cleanly closes the environment node.
   - If an `\end{b}` tag mismatches `\begin{a}`, a non-fatal `"Mismatched environment: began with 'a', but ended with 'b'"` error is logged, while tree construction completes normally.
5. **Missing Argument Recovery**:
   - Commands requiring arguments (`\section`, `\label`, `\ref`, `\cite`) verify the presence of `{`. If missing, an error is recorded without consuming downstream commands or text.

## Consumers & Dependents

- **LSP Daemon (`ferrotexd`)**:
  - [[crates/ferrotexd/src/completer.rs|completer.rs]] — Contextual autocompletion of commands and environments.
  - [[crates/ferrotexd/src/diagnostics/mod.rs|diagnostics]] — Diagnostic passes for syntax errors and semantic validation (e.g., unclosed math delimiters in `diagnostics/math.rs`).
  - `crates/ferrotexd/src/workspace.rs` — Scans the CST to index labels, cross-references, citations, and inclusions across the workspace.
  - `crates/ferrotexd/src/lib.rs` — Core LSP protocol handlers for `textDocument/didChange`, `textDocument/definition`, `textDocument/documentSymbol`, and `textDocument/references`.
  - `crates/ferrotexd/src/fmt.rs` — Source code formatter relying on the CST to reformat documents without losing whitespace or comments.
  - `crates/ferrotexd/src/hover.rs` — Node extraction and documentation tooltips for symbols under the cursor.
